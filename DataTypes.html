We are learning DataTypes in javascript

There are 2 Types of DataTypes in JavaScript:

  • Primitive
  • Non-Primitive

Primitive DataTypes

  • Number
  • String
  • Boolean
  • Undefined
  • Null
  • Symbol
  • BigInt

Non-Primitive DataTypes

  • Object
  • Array
  • Function

To check what type of data a variable holds, you can use the typeof operator.
